# Feature index

This index lists every feature document below `docs/features/`, grouped by
area, with its title, status, modules and theorems. It is to be generated by
`cargo xtask docs index` (planned) from the feature documents and is not
edited by hand once that command exists. See the
[documentation conventions](../conventions/documentation.md) for the form of
a feature document.

The [subject domains](../domains/README.md) describe the target scope,
whether krepi provides a feature or not.
